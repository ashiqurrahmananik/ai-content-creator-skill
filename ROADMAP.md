# Roadmap

## v0.1 — released

- YouTube Shorts and Facebook Reels research with direct Shorts links
- `Cartoon-ready` / `All videos` scope
- Three-file script discipline with `[ ]` tags and `[[[ ]]]` notes
- Hybrid ElevenLabs / offline Kokoro auto voice with narrator and dialogue voices
- Preview approval before full generation
- OpenCode skill, agent, slash command
- Rebuilt Claude Code skill with Agent Skills frontmatter
- Worked example and GitHub publish guide

## v0.2 — next

- Unit tests for `auto_voice.py`: quote splitting, pronoun attribution, gap timing
- `--dry-run` mode that prints segments without generating audio
- One-command install scripts for OpenCode and Claude Code
- GitHub Action expanded to run the tests, not just syntax checks

## v0.3 — planned

- Non-English script timing guide with Whisper `words.json`
- More voice-provider presets in `voices.json`
- A small gallery of finished films and their briefs
- Optional CSV/JSON export of trend reports

## v1.0 — later

- Distribution as a Claude plugin / marketplace entry
- OpenCode package manifest
- Reproducible demo kit that regenerates the example film end to end
